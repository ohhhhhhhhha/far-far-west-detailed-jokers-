# Contributing / 参与维护

This repository contains only FFWJokerInfo. Keep related changes together and unrelated changes in separate commits. Adopt [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) as a project convention, not a GitHub requirement: type(scope): description. Use scopes cards, docs or release, and types feat, fix, docs, refactor, build or test. Prefer short descriptive titles and explain the reason and validation when useful.

README files should state the purpose, features, prerequisites, installation, usage, support and license. Keep English and Chinese consistent. Use relative links for repository files and releases for downloads. Put longer developer details in DEVELOPMENT.md. Follow the [GitHub README guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) and [commit-history guidance](https://docs.github.com/en/desktop/managing-commits/options-for-managing-commits-in-github-desktop).

Include only allowlisted source and distribution files. Never commit saves, player Data, logs, credentials, private identifiers, local paths, backups or game dumps. Verify the affected behavior; do not present offline results as live-game tests. Avoid rewriting pushed history for cosmetic changes.

本仓库只维护 FFWJokerInfo。按相关改动分组提交，采用 type(scope): description 约定；中英文 README 保持用途、安装、操作、限制、反馈和许可一致。不得提交存档、玩家 Data、日志、密钥、个人路径、备份或游戏原始导出；验证应对应实际改动。
